# Oasis B2B

Карманная база организаций Ташкента и мини-CRM для B2B-продаж Oasis Touristik.

Открыть: https://moxir1998.github.io/oasis-b2b/

На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».

Данные об организациях: © участники OpenStreetMap (ODbL). Контакты и заметки CRM хранятся только на телефоне.
